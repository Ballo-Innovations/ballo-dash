# Lens — one-pager
**What:** Unified brand, communications and market intelligence for Infratel: social/web/email/paid-media KPIs in one dashboard; real-time social listening with explainable sentiment, trend detection and crisis alerts; competitor benchmarking and share of voice; CSAT/NPS/perception surveys; AI insight feed, forecasting and campaign recommendations; one-click scheduled reports.
**Different because:** every number carries its source; every sentiment score is explainable; crisis detection comes with evidence and a response; recommendations come with projected reach and a budget.
**Data honesty:** live news (RSS), live first-party web tracker, live surveys, CSV imports for GA4/Meta/Mailchimp/X; social stream simulated with connectors written to real API shapes.
**Tech:** Next.js 15 · TypeScript · Postgres/Prisma · worker + connectors · SSE · @react-pdf · MinIO · Anthropic API (cached) · Docker Compose · CI · Vitest/Playwright.
